# ChsBuffer.Avalonia.AppHost.win-arm64

Prelinked Avalonia 12 apphost and single-file host templates for .NET 10 `win-arm64`, with ANGLE, SkiaSharp, and HarfBuzzSharp native libraries statically linked.

This package brings in the shared Build integration automatically. Use `ChsBuffer.Avalonia.AppHost` instead to include every supported RID.
